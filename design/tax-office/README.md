# 세무법인 올바른 홈페이지 디자인 시안

Claude Design 캔버스(`.dc.html`) 원본 파일입니다. 각 폴더의 `canvas.json`이 아트보드 배치를 정의합니다.

| 폴더 | 내용 |
|---|---|
| `v1/` | 첫 시안 — 데스크톱(반응형) + 모바일 390px |
| `v2/` | 핀테크형 개선안 — 칩 선택, 4단계 프로세스, SVG 아바타 (V1 비교 포함) |
| `v3/` | 네이비 브랜드 디자인 시스템 — 시스템 보드, 변경 근거 보고서 (V2 비교 포함) |
| `v3-ai-diagnosis/` | V3 홈 + 간이 AI 세무 진단 프로토타입 (규칙 기반 모의 진단) + 서브페이지(서비스·세무사·절세 사례·회사 소개·상담 예약), 공통 헤더/푸터 |

- 성과 수치·사례·후기·세무사 정보는 모두 `[ ]` 자리표시자입니다.
- AI 진단의 세법 기준(공제 한도·세율·의무 기준)은 출시 전 세무사 검토가 필요합니다.
